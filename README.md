# Vue 3 + Webpack

Страница оформления заказа на Vue 3 (Composition API) с Webpack 5 и CSS Modules.

## Запуск

Требуется Node.js 22.15+.

- `npm install` — установка зависимостей.
- `npm run dev` — запуск сервера разработки на `http://localhost:5173` с горячим обновлением.
- `npm run build` — production-сборка в `dist`.
- `npm run preview` — локальный просмотр готовой сборки на `http://localhost:4173` (после `npm run build`).
- `npm run lint` — проверка JavaScript и Vue-компонентов с ESLint.

Отправка заказа имитируется задержкой 1,5 секунды, без обращения к серверу.
